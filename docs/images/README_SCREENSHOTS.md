# README image notes

These six PNGs were supplied by the project author on 2026-09-27. They are captures of the running Mode2 interface and its exported PDF, copied without altering their visual content. The project uses a synthetic Markdown source (`demo-coastal-notes.md`), sample Chinese translations, and offline demonstration review/concept responses.
